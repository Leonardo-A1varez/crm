## Fuentes no aceptadas como contrato

- Blogs de terceros, Stack Overflow, foros y cifras comunitarias.
- Ejemplos Postman con versión antigua usados para afirmar vigencia de esa versión.
- Newsroom para afirmar disponibilidad en una cuenta concreta.
- Ausencia en búsquedas como prueba absoluta de que una API nunca existe. En grupos, calling y productos regionales la conclusión correcta es “no prometer hasta verificar”.
